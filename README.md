# Student Performance Dashboard 📊

## 📌 Project Overview

The **Student Performance Dashboard** is a data analysis and visualization project developed using Microsoft Excel. It analyzes students' academic performance based on total scores, grades, attendance percentage, weekly self-study hours, and class participation.

The dashboard presents important academic insights through KPI metrics, charts, and interactive filters, helping users understand student performance patterns and explore factors associated with academic outcomes.

## 🎯 Project Objectives

- Analyze students' academic performance and total scores.
- Understand grade distribution across students.
- Examine the relationship between attendance and academic scores.
- Analyze weekly self-study hours and their association with performance.
- Track key performance indicators (KPIs) using a dashboard.
- Present data in a clear and interactive visual format.

## 🛠️ Tools and Technologies

- **Microsoft Excel**
- PivotTables and PivotCharts
- Excel formulas and calculations
- Charts and data visualization
- Slicers and interactive filters

## 📊 Dashboard Features

### 1. KPI Metrics
Displays key academic indicators, such as:
- Average Total Score
- Average Attendance Percentage
- Average Weekly Self-Study Hours
- Student Count

### 2. Grade Distribution
Visualizes the number of students in each grade category, helping identify the most common grades.

### 3. Average Score Analysis
Helps compare academic scores across different grade categories.

### 4. Attendance Analysis
Examines student attendance percentages and their relationship with academic performance.

### 5. Study Hours Analysis
Explores the association between weekly self-study hours and students' total scores.

### 6. Interactive Dashboard
Uses slicers and filters, where configured, to explore the data and update relevant dashboard visuals.

## 🔍 Key Findings

Based on the available student data:

- The average total score is approximately **84.47 out of 100**.
- The average attendance percentage is approximately **84.73%**.
- Average weekly self-study time is approximately **15.06 hours**.
- Grade A is the most common grade among the records with complete core data and an assigned grade.
- Self-study hours show a strong positive association with total scores in the available data.

These findings describe patterns in the dataset and do not establish that any single factor directly causes higher academic performance.
